Question 1 (Exercise 2):
    The macro MPBOOTPHYS is needed to calculate the absolute address.
    The linked address is above KERNBASE, while the actual code is copied into a lower memory
    region. Thus, we need the macro to ensure that we access instructions that exist, which 
    prevents faults (accessing virtual memory that does not yet exist)
